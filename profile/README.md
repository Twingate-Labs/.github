# Twingate‑Labs Org

Welcome to **Twingate-Labs** — the sandbox where ideas, experiments, and side projects come to life.

This org is where we explore creative ways to extend, automate, or just have fun with Twingate. It’s a space for prototypes, proof-of-concepts, bots, tools, and utilities that may or may not make it into production—but they’ll definitely spark ideas.

## What’s in the Lab

- **[Twingate‑CLI](https://github.com/Twingate-Labs/Twingate-CLI)** – Official Python CLI for the Twingate Admin API. Full API parity with 57 operations across 15 entity types, concurrent pagination, CSV/JSON/DataFrame output
- **[tgcli‑web‑py](https://github.com/Twingate-Labs/tgcli-web-py)** – Browser-based admin console built on Twingate-CLI. Export/import with full CRUD, real-time diff review, health dashboard, entity browsing. Docker and pip install
- **[tg‑cli](https://github.com/Twingate-Labs/tg-cli)** – [Deprecated] CLI for managing Twingate via Deno/JavaScript  
- **[tg‑aws‑tag‑sync](https://github.com/Twingate-Labs/tg-aws-tag-sync)** – AWS Lambda that syncs AWS resource tags into Twingate resources & groups
- **[tg‑coder](https://github.com/Twingate-Labs/tg-coder)** – Demo integration for using Twingate with Coder  
- **[tg‑group‑profile‑manager](https://github.com/Twingate-Labs/tg-group-profile-manager)** – Slack bot for self-serve control over Twingate group access  
- **[tg‑group‑profile‑manager‑helm](https://github.com/Twingate-Labs/tg-group-profile-manager-helm)** – Helm chart to deploy the Slack bot easily  
- **[tg‑client‑k8s‑sidecar](https://github.com/Twingate-Labs/tg-client-k8s-sidecar)** – Demonstrates using Twingate’s headless client as a Kubernetes sidecar  
- **[tg‑render](https://github.com/Twingate-Labs/tg-render)** – Demo deploying the connector on Render.com  
- **[tg‑ip‑lookup](https://github.com/Twingate-Labs/tg-ip-lookup)** – Lightweight tool to detect cloud provider info for IPs  

## What’s the vibe here?

These tools are **not polished production-grade solutions**—they’re prototypes, hobby projects, and sandbox ideas. Think “inspiration starter kit” rather than full-featured products. Inspired? Remix them, learn from them, and take them further.
